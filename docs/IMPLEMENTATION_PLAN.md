# Implementation documentation index

Product decisions and future work belong to the existing Clicky Plane project and its canonical product specification Page. This file is retained as a compatibility link, not an authoritative task plan.

- [Visual guide architecture and protocol](VISUAL_GUIDE_PROTOCOL.md)

The implementation preserves the blue companion, shortcut/editor behavior, offline preview, and legacy directory/scheme. Voice development, desktop execution, terminal attachment, and MCP integration are excluded from the current visual-guide delivery. Release capabilities stay gated until native acceptance passes. Plane changes require separate approval.
